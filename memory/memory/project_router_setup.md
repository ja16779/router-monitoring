Flint-2 (GL-MT6000) y Beryl (GL-MT3000) corren **OpenWrt puro** (no GL.iNet firmware).

**Why:** Usuario lo mencionó explícitamente para evitar asumir comportamientos específicos de GL.iNet.
**How to apply:** No asumir menús o features de GL.iNet UI. Usar UCI, init.d, procd, y comandos OpenWrt estándar.
